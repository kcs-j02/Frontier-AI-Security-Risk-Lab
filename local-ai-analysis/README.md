# Local AI Security Risk Analysis Lab



## Purpose

Evaluate AI-based cybersecurity risk analysis

using SSH configurations and firewall rules.



## Environment

- Kali Linux: Security testing

- Ubuntu Server: SSH server and local AI execution

- Windows 11: Authorized management client

- pfSense: Firewall

- Ollama / Gemma 3: Local AI



## Workflow

1. Collect SSH configuration and firewall information.

2. Analyze security risks using local AI.

3. Compare AI findings with connection tests.

4. Verify mitigation effectiveness.

5. Generate an evaluation report.



## Technologies

- VMware Workstation

- Python

- Ollama

- Gemma 3

- OpenSSH

- pfSense



## Findings

- AI identified some configuration risks.

- AI also misinterpreted firewall and SSH settings.

- Actual connection tests were necessary to verify findings.
